Section 1 — Endogeneity: แนวคิดพื้นฐาน (ข้อ 1–5)
1
ภาวะตัวแปรภายใน (Endogeneity) คืออะไร และเงื่อนไขทางคณิตศาสตร์ที่แสดงว่าเกิดปัญหานี้คืออะไร?
✅ เฉลย
Endogeneity คือสถานการณ์ที่ตัวแปรอิสระ X สัมพันธ์กับ error term u ทำให้ OLS แยกผลของ X ต่อ Y ไม่ได้อย่างบริสุทธิ์ เงื่อนไขคือ Cov(X,u) ≠ 0 หรือเทียบเท่า E(u|X) ≠ 0 ซึ่งละเมิด exogeneity assumption ของ OLS
2
OLS มีทั้ง Bias และ Inconsistency เมื่อเกิด Endogeneity — ทั้งสองคำนี้ต่างกันอย่างไร?
✅ เฉลย
Bias = E[β̂] ≠ β ในตัวอย่างใดๆ; Inconsistency = แม้ n→∞ ก็ยังไม่ลู่เข้าหาค่าจริง (plim β̂ ≠ β) เพราะ Cov(X,u) ≠ 0 เป็นระบบ ไม่ใช่ noise — ข้อมูลมากขึ้นไม่ช่วย!
3
จากสูตร plim β̂₁ = β₁ + Cov(X,u)/Var(X) พจน์ที่สองหมายความว่าอะไร?
✅ เฉลย
Cov(X,u)/Var(X) คือ "ส่วนเกิน" ที่ OLS รวมเข้ากับ β̂₁ โดยไม่รู้ตัว เกิดจาก X เคลื่อนไหวพร้อมกับปัจจัยแฝงใน u ทำให้ OLS เข้าใจผิดว่าผลต่อ Y มาจาก X ทั้งหมด (Var(X) อยู่ตัวหาร → ถ้า X แปรผันมาก bias เล็กลง แต่ไม่หายไป)
4
Exogeneity Assumption E(u|X)=0 หมายความว่าอะไรในเชิงเศรษฐศาสตร์ และเหตุใดจึงสำคัญ?
✅ เฉลย
E(u|X)=0 หมายความว่าเมื่อกำหนด X แล้ว ไม่มีรูปแบบเป็นระบบของปัจจัยแฝงใน u ที่สัมพันธ์กับ X — X ไม่ "ปนเปื้อน" ปัจจัยอื่น ถ้าละเมิด β̂₁ สะท้อนทั้งผลของ X และปัจจัยแฝงพร้อมกัน ตีความเป็น causal effect ไม่ได้
5
มี 4 แหล่งหลักที่ทำให้เกิด Endogeneity จงระบุและให้ตัวอย่างเศรษฐศาสตร์สั้นๆ ของแต่ละแหล่ง
✅ เฉลย
(1) OVB — ละ Ability ออกจากสมการค่าจ้าง; (2) Simultaneity — P↔Q กำหนดกันในตลาด; (3) Measurement Error — ผู้ตอบจำปีการศึกษาผิด; (4) Sample Selection / Endogenous Assignment — เห็นค่าจ้างเฉพาะคนมีงานทำ หรือทุนให้คนเก่ง (ทั้งหมดนำไปสู่ Cov(X,u) ≠ 0)
Section 2 — Omitted Variable Bias (ข้อ 6–10)
6
สูตร OVB คือ Bias = β₂·Cov(X,Z)/Var(X) เงื่อนไขใดทำให้ Bias=0?
✅ เฉลย
Bias=0 เมื่อ β₂=0 (Z ไม่มีผลต่อ Y) หรือ Cov(X,Z)=0 (X ไม่สัมพันธ์กับ Z) ต้องละเมิดทั้ง 2 เงื่อนไขพร้อมกันจึงเรียกว่า OVB — ถ้าลืมใส่ตัวแปรที่ไม่สัมพันธ์กับ X เลย ไม่เป็น OVB แค่ R² ต่ำกว่าที่ควร
7
True model: Income = 20,000 + 2,000·Educ + 10,000·Ability และ Ability = 0.2·Educ + v OLS ไม่ใส่ Ability จะได้ coefficient ของ Education เท่าใด?
✅ เฉลย
Bias = β₂×δ₁ = 10,000×0.2 = 2,000 → OLS ได้ α̂₁ = 2,000+2,000 = 4,000 บาท/ปี (สูงเกินจริง 100%) เพราะ Ability ที่มีผลต่อรายได้ถูกรวมอยู่ใน error term
8
ถ้าละ "ความอุตสาหะ" ออกจากสมการค่าจ้าง OLS จะประมาณผลของการศึกษาสูงหรือต่ำเกินจริง? เพราะเหตุใด?
✅ เฉลย
สูงเกินจริง (Upward Bias) เพราะ β₂>0 (ความขยันเพิ่มค่าจ้าง) และ Cov(Educ, Diligence)>0 (คนขยันมักเรียนสูง) → sign(Bias)=(+)×(+)=บวก OLS นับผลของความขยันเข้าไปในสัมประสิทธิ์การศึกษา
9
จงพิสูจน์ว่า Cov(X,Y) = β₁Var(X) + β₂Cov(X,Z) จาก True Model: Y = β₀ + β₁X + β₂Z + u
✅ เฉลย
Cov(X,Y) = Cov(X, β₀+β₁X+β₂Z+u) linearity of Cov: = Cov(X,β₀) + β₁Cov(X,X) + β₂Cov(X,Z) + Cov(X,u) Cov(X,β₀)=0; Cov(X,u)=0 (exogeneity in true model) = β₁Var(X) + β₂Cov(X,Z) ✓
10
ให้ Corr(X,Z)=0.30, SD_X=3, SD_Z=1, β₂=0.20, Var(X)=9, β₁=0.08 จงคำนวณ Bias และ α̂₁ ที่ OLS ประมาณได้
✅ เฉลย
Cov(X,Z) = 0.30×3×1 = 0.90 Bias = 0.20×0.90/9 = 0.020 E[α̂₁] = 0.08+0.020 = 0.10 (สูงเกินจริง 25%)
OLS บอกว่าเรียนเพิ่ม 1 ปี ค่าจ้างเพิ่ม 10% ทั้งที่ผลจริงแค่ 8% — ส่วน 2% มาจาก Ability
Section 3 — Simultaneity / Measurement Error / Sample Selection (ข้อ 11–17)
11
ในระบบ Q_d = α₀−α₁P+u_d, Q_s = β₀+β₁P+u_s จงพิสูจน์ว่า Cov(P*,u_d) ≠ 0
✅ เฉลย
จาก Qd=Qs: P* = (α₀−β₀)/(α₁+β₁) + u_d/(α₁+β₁) − u_s/(α₁+β₁) Cov(P*,u_d) = Var(u_d)/(α₁+β₁) ≠ 0 P* มี u_d เป็นส่วนประกอบ → ไม่ใช่ exogenous
12
Q_d=100−2P+u_d, Q_s=20+3P+u_s: หา (P*,Q*) ที่ baseline, demand shock u_d=+20, supply shock u_s=+20 และ OLS จะผิดพลาดอย่างไร?
✅ เฉลย
Baseline: P*=16, Q*=68 u_d=+20: P=20, Q=80 (ราคา↑ปริมาณ↑) u_s=+20: P=12, Q=76 (ราคา↓ปริมาณ↑)
OLS ปะปนทั้งสองกรณี → slope อยู่ระหว่าง −2 กับ +3 ไม่ใช่ structural slope ของฝ่ายใดเลย
13
Simultaneity Bias เป็น "Systematic" ไม่ใช่ Random — จงอธิบายว่าทำไมมันทำให้ OLS Inconsistent ไม่ใช่แค่ Biased
✅ เฉลย
"Systematic" = Cov(X,u) ≠ 0 เกิดจากโครงสร้างของแบบจำลอง ไม่ใช่ random sampling — ทุกครั้งที่สุ่มตัวอย่างใหม่ X ก็ยังสัมพันธ์กับ u เสมอ ดังนั้น แม้ n→∞ ค่าเฉลี่ยของ Cov(X,u) ก็ไม่ลู่เข้าศูนย์ → plim β̂ ≠ β คือ Inconsistent
14
จงอธิบายกลไกที่ Measurement Error ทำให้ Cov(X_obs, u*) ≠ 0 โดยเริ่มจาก X_obs = X_true + e
✅ เฉลย
Y = β₁X_true+u = β₁(X_obs−e)+u = β₁X_obs + (u−β₁e) ↑ u* composite error Cov(X_obs,u*) = −β₁Var(e) ≠ 0 X_obs มี e → e อยู่ใน u* ด้วย → สัมพันธ์กัน
15
Attenuation Bias คืออะไร? สูตร E[β̂₁] = β₁·Var(X_true)/[Var(X_true)+Var(e)] แสดงให้เห็นอะไร?
✅ เฉลย
Attenuation Bias = β̂₁ ถูก "ดึง" เข้าหาศูนย์เสมอ (ใน Classical ME) เพราะ noise (e) เพิ่ม Var(X_obs) ใน denominator แต่ Cov(X_obs,Y) ยังขึ้นกับ X_true อย่างเดียว → Shrinkage Factor λ = Var(X_true)/[Var(X_true)+Var(e)] < 1 ยิ่ง Var(e) มาก ยิ่ง bias รุนแรง
16
Sample Selection Bias ต่างจาก OVB อย่างไร? ให้ตัวอย่างที่สองปัญหาเกิดพร้อมกันในงานวิจัยเดียว
✅ เฉลย
OVB = ตัวแปร Z ขาดจากสมการ แต่ข้อมูลครบทุกคน; Sample Selection = ข้อมูลบางกลุ่มหายไปจากตัวอย่างอย่างไม่สุ่ม — ตัวอย่างที่เกิดพร้อมกัน: ศึกษาผลการฝึกอบรม (X) ต่อผลิตภาพ โดยเห็นเฉพาะคนที่ยังทำงานอยู่ (Selection) และไม่ควบคุม Motivation (OVB)
17
Survivorship Bias คืออะไร? จงให้ตัวอย่างในบริบทการเงิน และอธิบายว่ามันทำให้ผลประมาณเบี่ยงเบนอย่างไร
✅ เฉลย
Survivorship Bias = เห็นเฉพาะ "ผู้รอดชีวิต" ไม่เห็นผู้ล้มเหลว — ตัวอย่าง: ศึกษา performance กองทุนรวม เห็นเฉพาะกองทุนที่ยังอยู่รอด (ผลงานดีพอ) กองทุนที่ปิดตัวหายไป → ค่าเฉลี่ยผลตอบแทน สูงกว่าความจริง และ coefficient ของปัจจัยทำนาย performance ก็บิดเบือนตามไปด้วย
Section 4 — Application & Critical Thinking (ข้อ 18–20)
18
นักวิจัยศึกษาผลของนโยบายลดดอกเบี้ย (X) ต่อการลงทุน (Y) แต่ธนาคารกลางมักลดดอกเบี้ยตอนเศรษฐกิจซบเซา — ปัญหา Endogeneity ประเภทใดเกิดขึ้น และ Cov(X,u) ≠ 0 เพราะอะไร?
✅ เฉลย
เกิดทั้ง Simultaneity (นโยบายตอบสนองต่อ Y → X↔Y) และ Endogenous Policy Assignment (การลดดอกเบี้ยเกิดตอนเศรษฐกิจแย่ไม่ใช่สุ่ม) — Cov(X,u)≠0 เพราะภาวะเศรษฐกิจ (ใน u ถ้าไม่ควบคุม) ส่งผลทั้งต่อ X และ Y พร้อมกัน → OLS อาจสรุปผิดว่า "ลดดอกเบี้ยทำให้การลงทุนลดลง"
19
Instrumental Variable ที่ดีต้องมี Relevance และ Exclusion Restriction — อธิบายทั้งสองข้อ และทำไม "ภาษีบุหรี่" จึงเป็น IV ที่ดีสำหรับผลการสูบบุหรี่ต่อสุขภาพ?
✅ เฉลย
Relevance: ภาษีสูงขึ้น → ราคาบุหรี่แพงขึ้น → คนสูบน้อยลง Cov(Z,X)≠0 (ทดสอบด้วย First-Stage F>10); Exclusion Restriction: ภาษีบุหรี่ไม่มีผลต่อสุขภาพโดยตรง นอกจากผ่านการสูบ Cov(Z,u)=0 (ข้อสมมติที่ต้องใช้ economic reasoning พิสูจน์ ทดสอบตรงๆ ไม่ได้)
20
เพื่อน ป.โท เสนอว่า "เราพบว่า Corr(X, ê) = 0 ในตัวอย่าง ดังนั้น OLS น่าจะ unbiased" — คุณเห็นด้วยหรือไม่? อธิบายข้อผิดพลาดในการใช้เหตุผลนี้
✅ เฉลย
ไม่เห็นด้วย — Corr(X, ê) = 0 เสมอโดยโครงสร้างทางคณิตศาสตร์ของ OLS (First-Order Condition กำหนดให้ Σ(Xᵢêᵢ)=0) จึงไม่มีข้อมูลใดเลยเกี่ยวกับ endogeneity — ê คือ residual ไม่ใช่ u ที่แท้จริง การทดสอบ Endogeneity ต้องใช้ Hausman Test หรือ First-Stage F-statistic
💡 ประโยคสำคัญ: OLS บังคับให้ Cov(X,ê)=0 เสมอ — ดังนั้น residual ≠ true error term และห้ามนำมาอ้างว่าไม่มี Endogeneity โดยเด็ดขาด
